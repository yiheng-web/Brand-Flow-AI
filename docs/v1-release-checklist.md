## 发布前仅剩的外部联调

- [ ] **真实 SiliconFlow**：部署方提供有效凭据并明确授权付费调用后，关闭 Demo；使用真实文本、视觉与生图模型重新跑纯图、图文、参考图、优化和质检链路，核对实际超时/429/额度以及生成质量。当前未执行付费模型请求。
- [ ] **生产 MinIO/S3**：本机 MinIO 镜像拉取被仓库访问拒绝，改用真实 Garage 完成本地 S3 兼容协议验收；不得据此宣称 MinIO 已验证。部署方需在目标私有桶核对 HeadBucket 权限、生产域名的 SigV4、Range、短签名到期、CORS 与指定版本下载。
- [ ] **目标部署环境**：配置正式 JWT、Mongo/Redis/存储凭据、HTTPS 网关及可信代理地址；在目标环境执行 readiness、鉴权 SSE、双账号业务回归，并验证持久化备份与保留旧镜像标签的回滚步骤。

## 已知边界

取消会阻止后续昂贵节点和服务端控制的重试；已发给外部 Provider 的请求仍可能完成或计费。新四候选生图预扣 4 张额度，失败不退回可能已经付费的额度。默认每用户同时运行 2 个任务、每日 40 张、每任务每 30 天最多 20 次显式重试/优化，可通过环境配置调整。

现有 React Flow 与 Ant Design 有非阻塞的控制台提示，Web 构建有包体积提示；本次验收未将这些提示伪装成失败，也未关闭规则或降低测试断言。生产依赖和外部模型的上述待验项完成前，不将本地 Demo 验收视为正式上线验收。
